# 一纸简历 Yizhi Jianli

开源、简洁的简历与证件照工作台。把履历排版、照片换底和文件导出放在一起，减少求职材料准备中的来回切换。

当前版本：**2.0.0-beta.2**。欢迎 Star、下载试用和反馈。

## 功能

- 十套自制 A4 模板：标准专业、极简黑白、清晰时间线、沉稳商务、经典简约、蓝色横条、极简线条、商务页眉、折角飘带、圆形时间轴。
- 空白简历选择模板会载入完整可编辑示例；已有草稿切换模板保留内容，也可通过“从示例开始”重新填写。点击预览姓名或某条经历，定位右侧对应的编辑字段。
- 实时预览、模块排序与显示开关；可保存仅包含样式的自定义模板。
- 基本信息可添加最多 12 项自定义名称与内容，如个人网站、微信、作品集；支持单独关闭展示或删除，空内容自动隐藏，保存与复制简历时保留。
- 项目经历支持简介、个人贡献、成果、技术栈和网站 / 源码链接。短项目地址跟在担任角色后面，同一行展示，长内容可换行，源码地址保留在末尾。各项可留空或单独关闭展示，关闭后保留内容；模板提供可编辑示例，旧项目正文继续保留。
- 项目“内容排版”提供紧凑、适中、舒展间距；个人贡献可一键按段落分点并撤销，保留原文与加粗。常用富文本工具优先展示，其他格式可展开，编辑区随内容增高。
- 浏览器自动保存草稿，刷新后继续编辑；每次进入时右侧编辑区默认展开，进入后可手动折叠，支持深色模式和减少动效。
- 免费账户：用户名与密码注册、账户恢复码找回、修改密码、导出本人数据和注销账户。基础制作与导出不要求登录。
- 主动保存到云端后自动同步，默认免费保存 10 份基础简历或岗位版本；支持复制、改名、删除，其他设备同时修改时拒绝覆盖并提示另存。
- 按岗位准备：使用真实基础简历与 JD 生成可编辑投递版本，检查修改对照后再采用。未连接 AI 时提供明确标注的基础整理；连接后按账户提供每日免费生成额度，生成失败不扣成功次数。
- 手机端整页上下滑动，通过“编辑栏目”切换表单；“管理栏目”展开排序、显示和改名功能，编辑与预览入口随滚动保持可用。
- 导出 A4 PDF，项目地址与源码地址保留可点击链接。PDF 正文为图片页面，暂不提供可搜索文本或 ATS 解析保证。
- MODNet CPU 人像抠图，免费快速换底；照片裁切、尺寸调整、边缘调整和 300 DPI 图片导出。
- 可选 AI 精修扩展：仅供本机私有配置使用，公开模式全部关闭。

## 本机启动

需要 Node.js 22 或更高版本（建议使用 LTS）以及 npm。Windows、macOS、Linux 可使用相同命令；原生图片与推理依赖需要受支持的系统架构。

```bash
npm ci
npm run setup-model
npm start
```

打开 [本机主页](http://127.0.0.1:8099/)。首页、简历编辑和证件照共用一个服务，不需要额外启动照片项目。

首次下载约 26 MB 的人像模型，后续启动不再下载。安装脚本校验 SHA-256；网络失败时可重新运行。新访客直接从可编辑的完整虚构示例开始，也可以选择空白简历。模板与“恢复示例”中的履历、联系方式和人物均为演示资料，请替换为自己的真实经历。

## 公开服务模式

```bash
npm run start:public
```

公开模式不读取个人照片 AI 精修配置，也禁止公开配置该照片连接或调用精修。免费换底、编辑、导出和账户功能正常工作。简历文本 AI 使用独立的服务端配置，默认关闭；管理员可在“账号与生成”中设置，也可通过环境变量初始化。前期全部免费，没有支付、订单或会员门槛。默认仍只监听 127.0.0.1；对外部署需由运行环境设置 BIND_HOST=0.0.0.0，并通过 HTTPS 反向代理访问。使用域名时设置 PUBLIC_ORIGIN 为完整站点来源，例如 `https://resume.example.com`。样例见 .env.example，应用不会自动读取该文件。

此项目需要 Node 后端执行图片处理和保存账户，不能直接完整部署到 GitHub Pages。当前版本适合本机使用和小规模公开试用；账号和云端版本已实现，仍需为高流量补充验证码、代理限流、监控和资源预算。JSON 存储只适用于一个 Node 进程；多实例使用 PostgreSQL。

## 免费账户与岗位版本

- 账户入口：`/account/`。用户名不代表经过实名或邮箱验证的自然人，后台不会把账号数称为真人数。初期无需邮件或短信服务；恢复码仅在注册、恢复或主动更换时显示，密码和恢复码仅保存哈希。
- 登录不会上传或覆盖已有草稿。点击“保存到云端”确认后才上传当前简历文字与已添加照片，后续编辑同步对应版本。停止同步、网络失败、账号失效或云端冲突时，本地自动保存继续工作。
- 从云端打开另一份简历、或采用岗位版本时，当前草稿保留为切换前备份，可从保存菜单恢复。数据保存上限约 2 MB，过大的照片需先缩小；本地重要资料仍应定期下载备份。
- 本机或单进程服务器保存到被 Git 排除的 `private/members/accounts.json`。设置 `DATABASE_URL` 后改存 PostgreSQL 的 `jy_members` 表，用户数据与后台管理表分开；Vercel 必须使用数据库，不能依赖临时文件。
- 文本 AI 默认未连接，不复用私人照片精修密钥。环境变量：`RESUME_AI_API_KEY`、`RESUME_AI_BASE_URL`、`RESUME_AI_MODEL`、`RESUME_AI_DAILY_LIMIT`（默认 3）。管理员保存的配置优先于环境初始值，密钥不会返回前端。
- 生成仅发送经历文字和 JD，不发送基本信息的姓名、手机、邮箱或照片字段。经历或 JD 内主动写入的其他个人信息仍可能发送，请先检查输入。输出保留原有身份、教育和经历条目的名称与日期；明显新增数字或技能的建议会被忽略，语义真实性仍需用户核实。
- 模型返回结构化建议，网站渲染、编辑和导出；用户确认后另存为岗位版。AI 无法连接时只展示基础整理，不伪装真实 AI 成功。真实第三方调用仍需管理员提供可用模型连接；自动化测试中的模型服务是替身。
- 后台“账号与生成”汇总注册、云端保存、实际使用、生成成功/失败、采用和导出操作，不提供查看私人简历的功能。生成和导出表示文件流程完成或下载被触发，不证明实际投递或获得面试。

## 隐私

未开启云端同步的简历、自定义模板和证件照草稿保存在当前浏览器。用户主动保存的简历会存到本站服务，账号数据可导出、删除或注销。管理员可关闭匿名使用统计；账户功能的必要使用汇总单独保存最多 90 天，不包含简历正文或照片。清理网站数据会清掉本地草稿，重要材料请及时导出。

快速换底在**运行本项目的服务器**处理图片：本机部署时照片留在本机，使用他人公开部署时图片会发送到对方服务器。图片使用内存处理与短期缓存，不写入上传目录。AI 精修会将图片发送到自己配置的第三方服务，因此仅作为明确启用的扩展。

密钥和用户资料不属于仓库内容。private/、.env、用户输出、上传文件和模型权重已排除提交；禁止强制提交这些路径。更多说明见 [SECURITY.md](SECURITY.md)。

## 管理后台

后台入口：`http://127.0.0.1:8099/admin.html`（也可访问 `/admin`）。与介绍页、简历和证件照共用服务。

后台直接使用管理员账户和密码登录，不提供网页注册。首次本机启动生成 `admin` 账户与随机初始密码，登录信息仅写入 `private/admin/管理员初始登录信息.txt`；登录后可在“账户安全”修改密码。也可在启动环境中设置 `ADMIN_USERNAME`、`ADMIN_PASSWORD` 指定初始账户。已有账户不会因重启或环境变量变化而重置；账户密码用 scrypt 哈希保存，Cookie 为 HttpOnly、SameSite=Strict，修改接口同时校验来源与管理员 CSRF 令牌。后台账户和会话与其他项目隔离。

- 数据概览、功能表现、访问来源：真实的匿名页面和功能操作统计，7/30/90 天或自选日期，CSV 导出。独立访问按日去重，不表示跨设备真实人数。
- 停留与离开：平均和中位页面可见时长、会话停留分布、最后退出页面、24 小时进入与退出量、未完成短停留率、各工具操作覆盖和排查建议，支持同样的日期筛选及独立 CSV。
- 模板管理：名称、说明、排序、启用、默认模板和首页展示（最多四套）。停用只影响新选择，不覆盖已有草稿的排版。用户自定义模板仍保存在各自浏览器。
- 网站内容：首页标题、关键词、介绍与 GitHub 地址，保存后新开或刷新页面生效；可下载不含账号及密钥的设置备份。
- 统计与接口：开关匿名统计、创建/撤销只读统计密钥。`GET /api/analytics/summary?days=30` 使用 `Authorization: Bearer ...`；密钥不能修改网站。密钥明文仅在创建时显示一次。
- 更新日志：版本标记、发布日期、类型、标题和多行内容；支持新增、编辑、删除以及保存冲突提示，仅在后台查看。
- 账号与生成：按日期查看账户和云端使用汇总；配置独立的简历文本 AI 地址、模型、密钥、启用状态和每日免费次数，密钥留空可保留现值。
- 账户安全：修改密码，其他登录会话失效。会话有效期 12 小时，重启服务后需重新登录。

网站设置、账号哈希和匿名统计均保存在被 Git 排除的 `private/admin/`。统计最多保留 90 天、100,000 条，只保存固定事件、设备类型、来源域名和按日匿名化的会话标识；不保存原始 IP、访客姓名、联系方式、简历正文或照片。登录管理员和带 `adminPreview=1` 的预览不计入。启用统计不会上传已有草稿或补造历史数据。

服务仍提供同源的照片处理，后台不查看、存储或删除用户照片。管理设置与用户浏览器草稿分开；不要把 `private/` 上传 GitHub。公网部署请配置 `PUBLIC_ORIGIN` 并通过 HTTPS 反向代理访问，后台暂不提供多管理员、密码找回或多人权限分工。

停留统计从更新后的新访问开始，旧事件不补造时长。可见页面每 15 秒上报累计值，切换标签页暂停，关闭或转页使用 Beacon；服务器去重乱序心跳。页面可见不代表用户一直注意页面。同一按日匿名标识的页面按 30 分钟间隔合并会话，正常末页关闭约 30 秒后计入退出，站内转页避免重复计算；心跳丢失或明确站内转页但未续接需等待 30 分钟推定，并单独标出，退出时段取最后心跳时间。匿名事件与页面访问快照各最多保留 90 天、100,000 条。

“未完成短停留”指累计可见不足 30 秒且没有成功导出或将照片用于简历的结束会话，是排查阈值，不是离开原因。小时短停留率按进入时段分组，以已结束会话为分母；小样本隐藏比例。工具操作覆盖可跳步，例如恢复草稿后直接导出，不作为强制线性漏斗。简历、照片导出和快速换底失败单独计入排查建议，不计为成功操作。对这个工具优先观察任务完成率、首次操作与失败情况；完成下载后离开是正常结果，不应通过强制弹窗延长停留。

## Vercel 部署

在线试用：[一纸简历](https://yizhijianli.cn/) · [管理后台](https://yizhijianli.cn/admin.html#changelog)。

使用 Node.js 22，仓库中的 vercel.json 已配置构建、静态资源、Node 函数与 CPU 模型。部署项目需要 PostgreSQL 数据库；本次生产使用 Vercel 与 Neon 免费档，新加坡区域。云端数据与本机 private/admin 数据分别保存，不会自动迁移私人配置。

1. 在 Vercel 导入仓库，选择 Other，使用仓库中的构建设置。
2. 连接 Neon PostgreSQL 集成，确认生产环境存在 DATABASE_URL。
3. 在生产环境设置 ADMIN_USERNAME、ADMIN_PASSWORD 和 PORTRAIT_REQUEST_SECRET。前两项仅在没有管理员时初始化账户，使用独立长密码；照片请求秘密使用独立随机字符串，用于跨实例请求校验。已有管理员不会因环境变量变化重置。
4. 部署后进入 /admin.html，使用服务端配置的管理员账户与密码登录。自定义域名时额外设置 PUBLIC_ORIGIN 为完整 HTTPS 来源，再部署。

Vercel 自动启用公开免费模式，个人照片 AI 精修配置不上传，也不会读取。本机管理数据保存到 private/admin，用户数据保存到 private/members；Vercel 将后台数据和用户主动保存的云端简历分表写入 PostgreSQL，会话可跨函数实例恢复。本地草稿、照片工作草稿与自定义模板仍保存在当前设备。种子日志仅用于首次建库，不覆盖后来编辑的日志。

快速换底会把处理副本提交到本站服务器；大图片自动缩小处理副本以适配函数上传上限，原始图片保留在浏览器。PNG/JPG 与六寸排版在浏览器生成并写入 300 DPI 元信息，不再把下载图片上传后端。模型首次加载可能增加等待；免费平台有资源额度，适合小规模试用，高流量需要另行规划资源。

本次验收实际走通公开首页、简历保存恢复、A4 PDF、照片换底、300 DPI 下载、照片用于简历与后台账户登录。PostgreSQL 的并发编辑、跨实例会话和来源校验由独立测试 schema 验证，测试不创建正式默认账号。运行 cloud 测试时用 CLOUD_TEST_DATABASE_URL 注入专用测试数据库；没有变量时相关测试跳过。
