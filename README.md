# 简影 Jianying

开源、简洁的简历与证件照工作台。把履历排版、照片换底和文件导出放在一起，减少求职材料准备中的来回切换。

当前版本：**2.0.0-beta.1**。欢迎 Star、下载试用和反馈。

## 功能

- 四套自制 A4 标准模板：标准专业、极简黑白、清晰时间线、沉稳商务。
- 实时预览、模块排序与显示开关；可保存仅包含样式的自定义模板。
- 浏览器自动保存草稿，刷新后继续编辑；右侧编辑区可折叠，支持深色模式和减少动效。
- 导出 A4 PDF。PDF 为图片页面，暂不提供可搜索文本或 ATS 解析保证。
- MODNet CPU 人像抠图，免费快速换底；照片裁切、尺寸调整、边缘调整和 300 DPI 图片导出。
- 可选 AI 精修扩展：仅供本机私有配置使用，公开模式全部关闭。

## 本机启动

需要 Node.js 22 或更高版本（建议使用 LTS）以及 npm。Windows、macOS、Linux 可使用相同命令；原生图片与推理依赖需要受支持的系统架构。

```bash
npm ci
npm run setup-model
npm start
```

打开 [本机主页](http://127.0.0.1:8099/)。首页、简历编辑和证件照共用一个服务，不需要额外启动照片项目。

首次下载约 26 MB 的人像模型，后续启动不再下载。安装脚本校验 SHA-256；网络失败时可重新运行。新访客从空白简历开始，“恢复示例”中的履历、联系方式和人物均为演示资料。

## 公开服务模式

```bash
npm run start:public
```

公开模式不读取 AI 私有配置，也禁止云端连接和付费调用。免费换底和编辑导出正常工作。默认仍只监听 127.0.0.1；对外部署需由运行环境设置 BIND_HOST=0.0.0.0，并通过 HTTPS 反向代理访问。使用域名时设置 PUBLIC_ORIGIN 为完整站点来源，例如 `https://resume.example.com`。样例见 .env.example，应用不会自动读取该文件。

此项目需要 Node 后端执行图片处理，不能直接完整部署到 GitHub Pages。当前版本适合本机使用和小规模公开试用；没有账号同步、跨设备草稿、分布式队列及完善的公网防滥用体系。高流量部署需补充代理限流、鉴权或验证码、监控和资源预算。

## 隐私

简历、自定义模板和证件照草稿保存在当前浏览器，不内置统计分析服务。清理网站数据会清掉草稿，重要材料请及时导出。

快速换底在**运行本项目的服务器**处理图片：本机部署时照片留在本机，使用他人公开部署时图片会发送到对方服务器。图片使用内存处理与短期缓存，不写入上传目录。AI 精修会将图片发送到自己配置的第三方服务，因此仅作为明确启用的扩展。

密钥和用户资料不属于仓库内容。private/、.env、用户输出、上传文件和模型权重已排除提交；禁止强制提交这些路径。更多说明见 [SECURITY.md](SECURITY.md)。

## 验证与开发

```bash
npm run setup-model
npm test
```

测试涵盖模板字段保留和排序、可选信息隐藏、自定义模板、导航保存、折叠及减少动效、模型推理、图片导出、公开模式和接口防护。GitHub Actions 使用 Node.js 22 执行相同测试。

首页模板预览由真实渲染器生成；scripts/prepare-template-previews.mjs 生成临时截图页面，截图完成后删除该页面。assets/img/templates/ 中的预览包含虚构示例履历。
