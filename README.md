# 一纸简历 Yizhi Jianli

开源、简洁的简历与证件照工作台。把履历排版、照片换底和文件导出放在一起，减少求职材料准备中的来回切换。

当前版本：**2.0.0-beta.2**。欢迎 Star、下载试用和反馈。

## 功能

- 十套自制 A4 模板：标准专业、极简黑白、清晰时间线、沉稳商务、经典简约、蓝色横条、极简线条、商务页眉、折角飘带、圆形时间轴。
- 空白简历选择模板会载入完整可编辑示例；已有草稿切换模板保留内容，也可通过“从示例开始”重新填写。点击预览姓名或某条经历，定位右侧对应的编辑字段。
- 实时预览、模块排序与显示开关；可保存仅包含样式的自定义模板。
- 浏览器自动保存草稿，刷新后继续编辑；每次进入时右侧编辑区默认展开，进入后可手动折叠，支持深色模式和减少动效。
- 手机端整页上下滑动，通过“编辑栏目”切换表单；“管理栏目”展开排序、显示和改名功能，编辑与预览入口随滚动保持可用。
- 导出 A4 PDF。PDF 为图片页面，暂不提供可搜索文本或 ATS 解析保证。
- MODNet CPU 人像抠图，免费快速换底；照片裁切、尺寸调整、边缘调整和 300 DPI 图片导出。
- 可选 AI 精修扩展：仅供本机私有配置使用，公开模式全部关闭。

## 本机启动

需要 Node.js 22 或更高版本（建议使用 LTS）以及 npm。Windows、macOS、Linux 可使用相同命令；原生图片与推理依赖需要受支持的系统架构。

```bash
npm ci
npm run setup-model
npm start
```

打开 [本机主页](http://127.0.0.1:8099/)。首页、简历编辑和证件照共用一个服务，不需要额外启动照片项目。

首次下载约 26 MB 的人像模型，后续启动不再下载。安装脚本校验 SHA-256；网络失败时可重新运行。新访客从空白简历开始，选择模板后可直接修改示例。模板与“恢复示例”中的履历、联系方式和人物均为演示资料，请替换为自己的真实经历。

## 公开服务模式

```bash
npm run start:public
```

公开模式不读取 AI 私有配置，也禁止配置 AI 连接和付费调用。免费换底和编辑导出正常工作。默认仍只监听 127.0.0.1；对外部署需由运行环境设置 BIND_HOST=0.0.0.0，并通过 HTTPS 反向代理访问。使用域名时设置 PUBLIC_ORIGIN 为完整站点来源，例如 `https://resume.example.com`。样例见 .env.example，应用不会自动读取该文件。

此项目需要 Node 后端执行图片处理，不能直接完整部署到 GitHub Pages。当前版本适合本机使用和小规模公开试用；没有账号同步、跨设备草稿、分布式队列及完善的公网防滥用体系。高流量部署需补充代理限流、鉴权或验证码、监控和资源预算。

## 隐私

简历、自定义模板和证件照草稿保存在当前浏览器，可由管理员关闭匿名使用统计。清理网站数据会清掉草稿，重要材料请及时导出。

快速换底在**运行本项目的服务器**处理图片：本机部署时照片留在本机，使用他人公开部署时图片会发送到对方服务器。图片使用内存处理与短期缓存，不写入上传目录。AI 精修会将图片发送到自己配置的第三方服务，因此仅作为明确启用的扩展。

密钥和用户资料不属于仓库内容。private/、.env、用户输出、上传文件和模型权重已排除提交；禁止强制提交这些路径。更多说明见 [SECURITY.md](SECURITY.md)。

## 管理后台

后台入口：`http://127.0.0.1:8099/admin.html`（也可访问 `/admin`）。与介绍页、简历和证件照共用服务。

首次进入后台，从 `private/admin/管理员首次设置码.txt` 复制设置码，创建自己的管理员账户与 10～128 字符的密码。没有默认密码。设置码仅能用一次；账户密码用 scrypt 哈希保存，Cookie 为 HttpOnly、SameSite=Strict，修改接口同时校验来源与管理员 CSRF 令牌。后台账户和会话与其他项目隔离。

- 数据概览、功能表现、访问来源：真实的匿名页面和功能操作统计，7/30/90 天或自选日期，CSV 导出。独立访问按日去重，不表示跨设备真实人数。
- 停留与离开：平均和中位页面可见时长、会话停留分布、最后退出页面、24 小时进入与退出量、未完成短停留率、各工具操作覆盖和排查建议，支持同样的日期筛选及独立 CSV。
- 模板管理：名称、说明、排序、启用、默认模板和首页展示（最多四套）。停用只影响新选择，不覆盖已有草稿的排版。用户自定义模板仍保存在各自浏览器。
- 网站内容：首页标题、关键词、介绍与 GitHub 地址，保存后新开或刷新页面生效；可下载不含账号及密钥的设置备份。
- 统计与接口：开关匿名统计、创建/撤销只读统计密钥。`GET /api/analytics/summary?days=30` 使用 `Authorization: Bearer ...`；密钥不能修改网站。密钥明文仅在创建时显示一次。
- 更新日志：版本标记、发布日期、类型、标题和多行内容；支持新增、编辑、删除以及保存冲突提示，仅在后台查看。
- 账户安全：修改密码，其他登录会话失效。会话有效期 12 小时，重启服务后需重新登录。

网站设置、账号哈希和匿名统计均保存在被 Git 排除的 `private/admin/`。统计最多保留 90 天、100,000 条，只保存固定事件、设备类型、来源域名和按日匿名化的会话标识；不保存原始 IP、访客姓名、联系方式、简历正文或照片。登录管理员和带 `adminPreview=1` 的预览不计入。启用统计不会上传已有草稿或补造历史数据。

服务仍提供同源的照片处理，后台不查看、存储或删除用户照片。管理设置与用户浏览器草稿分开；不要把 `private/` 上传 GitHub。公网部署请配置 `PUBLIC_ORIGIN` 并通过 HTTPS 反向代理访问，后台暂不提供多管理员、密码找回或多人权限分工。

停留统计从更新后的新访问开始，旧事件不补造时长。可见页面每 15 秒上报累计值，切换标签页暂停，关闭或转页使用 Beacon；服务器去重乱序心跳。页面可见不代表用户一直注意页面。同一按日匿名标识的页面按 30 分钟间隔合并会话，正常末页关闭约 30 秒后计入退出，站内转页避免重复计算；心跳丢失或明确站内转页但未续接需等待 30 分钟推定，并单独标出，退出时段取最后心跳时间。匿名事件与页面访问快照各最多保留 90 天、100,000 条。

“未完成短停留”指累计可见不足 30 秒且没有成功导出或将照片用于简历的结束会话，是排查阈值，不是离开原因。小时短停留率按进入时段分组，以已结束会话为分母；小样本隐藏比例。工具操作覆盖可跳步，例如恢复草稿后直接导出，不作为强制线性漏斗。简历、照片导出和快速换底失败单独计入排查建议，不计为成功操作。对这个工具优先观察任务完成率、首次操作与失败情况；完成下载后离开是正常结果，不应通过强制弹窗延长停留。

## Vercel 部署

在线试用：[一纸简历](https://yizhijianli.cn/) · [管理后台](https://yizhijianli.cn/admin.html#changelog)。

使用 Node.js 22，仓库中的 vercel.json 已配置构建、静态资源、Node 函数与 CPU 模型。部署项目需要 PostgreSQL 数据库；本次生产使用 Vercel 与 Neon 免费档，新加坡区域。云端数据与本机 private/admin 数据分别保存，不会自动迁移私人配置。

1. 在 Vercel 导入仓库，选择 Other，使用仓库中的构建设置。
2. 连接 Neon PostgreSQL 集成，确认生产环境存在 DATABASE_URL。
3. 在生产环境设置 ADMIN_SETUP_CODE 和 PORTRAIT_REQUEST_SECRET，两项分别使用独立的随机长字符串。首次设置码用于创建管理员，照片请求秘密用于跨实例请求校验。保留这些值，重新部署时不要随意更换。
4. 部署后进入 /admin.html，使用设置码创建自己的管理员账户；没有默认密码。自定义域名时额外设置 PUBLIC_ORIGIN 为完整 HTTPS 来源，再部署。

Vercel 自动启用公开免费模式，个人 AI 精修配置不上传，也不会读取。本机模式保存到 private/admin；Vercel 将网站设置、账号哈希、更新日志、匿名事件和限流写入 PostgreSQL，12 小时会话可跨函数实例恢复。浏览器里的简历、照片与自定义模板仍只在当前设备保存。种子日志仅用于首次建库，不覆盖后来编辑的日志。

快速换底会把处理副本提交到本站服务器；大图片自动缩小处理副本以适配函数上传上限，原始图片保留在浏览器。PNG/JPG 与六寸排版在浏览器生成并写入 300 DPI 元信息，不再把下载图片上传后端。模型首次加载可能增加等待；免费平台有资源额度，适合小规模试用，高流量需要另行规划资源。

本次验收实际走通公开首页、简历保存恢复、A4 PDF、照片换底、300 DPI 下载、照片用于简历与后台首次设置入口。PostgreSQL 的并发编辑、跨实例会话和来源校验由独立测试 schema 验证，测试不创建正式默认账号。运行 cloud 测试时用 CLOUD_TEST_DATABASE_URL 注入专用测试数据库；没有变量时相关测试跳过。
